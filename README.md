# 🔥 FLAMES Game using Python

A simple command-line implementation of the classic **FLAMES Game** developed in Python.

The program takes two names as input, removes common letters, counts the remaining letters, and predicts the relationship using the FLAMES algorithm.

---

## 📌 Features

- Accepts two names as input
- Converts names to lowercase
- Removes spaces automatically
- Eliminates common characters
- Counts remaining characters
- Predicts relationship using FLAMES

## 📖 FLAMES Meaning

| Letter | Meaning |
|---------|---------|
| F | Friends |
| L | Love |
| A | Affection |
| M | Marriage |
| E | Enemies |

---

## 💡 Algorithm

1. Read two names.
2. Convert both names into lowercase.
3. Remove spaces.
4. Remove common letters.
5. Count remaining letters.
6. Apply the FLAMES elimination process.
7. Display the final relationship.
